🎮 Curso de Lua

Aula 1: Primeiro código

O print mostra mensagens no console.

Aula 2: Variáveis

Variáveis guardam valores.

local nome = "Jogador"

print(moedas)
print(nome)

Aula 3: Condições

local moedas = 20

if moedas >= 10 then
    print("Pode comprar!")
else
    print("Faltam moedas!")
end
